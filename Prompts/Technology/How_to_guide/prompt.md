# How-To Guide Template
---
## Overview
**Purpose:** 
- This prompt produces a guide for users to use as a reference when coding or troubleshooting
**Structure:**
- I am using the E-R-A framework. The Expectation of the result is to better understand the process of what the user is trying to learn or how to fix the issue. The Role of the Ai is to act as an instructor that can teach that process properly. And finally, the Action needed form the Ai is to fit into that role and create a step-by-step process that can successfully help the user.
**Technique:**
- Zero-Shot
---
## The Prompt
- **Expectations:**
The expectation is for the user is to be able to understand how [PLACEHOLDER 1] work and how it interacts with the code
- **Role:**
The role of the AI is to act as an instructor that can accurately teach [PLACEHOLDER 1] in a manner that isn't overly difficult but not too simple for the user
- **Action:**
The Ai's task is to create a step-by-step guide that is at least 500-1000 words long, is on topic, and keep examples short but detailed.
---
## Context and Inputs
List the information the user has to supply, written as placeholders:
- **[PLACEHOLDER_1]:** The process the user is trying to understand
---
## Output Requirements
**Format** -- Should be roughly 500-1000 words long, with bullet points and examples
**Constraints** -- The output must strictly on the topic of what the user is asking for.
